        | # N-gramm's Frequency Analizator
        | 
        | N-gramm's Frequency Analizator - программа, которая позволяет сделать статический анализ частотности N-грамм на основе представляемого текста. Учитывается частота относительно уникальных слов, с упором на составления Буквенно-Образные Коды|БОК.
        | 
        | ## Функции
        | - Анализировать уникальные слова(в идеале уникальность на основе лемм) и составлять таблицу частотности N-грамм.
        | - Выбирать оптимальный набор N-грамм для составления БОК(два режима: gsc(жадный алгоритм), bpe(токенизация по частоте))
        | - работа через изменение главного файла, вывод в консоль
        | 
        | ## Технологии
        | - Language: Python 3.12
        | - Frameworks: -
        | 
        | ## Использование
        | ### Установка
        | 1. Клонировать репозиторий: `git clone ...`
        | 
        | ### Использование
        | 1. Перейти в папку `src`
        | 2. Закинуть файл в проект и изменить строку 5 в `main.py`
        | 3. Запустить командой `python main.py`
        |

            | @dataclass(frozen=True)
            | class WordItem:
            |     """Сontainer for a word.
            | 
            |     Attributes:
            |         text: The word(must not be empty).
            |         weight: Importance weight (must be >= 0).
            |     
            |     Raises:
            |         ValueError: If text is empty or weight is negative.
            |     """
            |     text: str
            |     weight: float
            | 
            |     def __post_init__(self):
            |         if not self.text.strip():
            |             raise ValueError("text must not be empty or whitespace")
            |         if self.weight < 0:
            |             raise ValueError("weight must be >= 0")
            |     
            |     @property
            |     def length(self)->int:
            |         return len(self.text)

            | 
            |     Attributes:

            |         min_word_length: Minimum length of words to consider (must be > 0).
            | 
            |     Raises:

            |             raise ValueError("min_word_length must be > 0")

            | class NGramVocab:
            |     """NGram vocabulary container.
            | 
            |     Attributes:
            |         max_size: Maximum vocabulary size (must be > 0).
            |         grams: Set of n-grams (must not contain empty strings).
            | 
            |     Raises:

            |         if len(self.grams) > self.max_size:
            |             raise ValueError("grams size exceeds max_size")
            |         if any(not gram.strip() for gram in self.grams):
            |             raise ValueError("grams must not contain empty strings")
